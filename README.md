# OWNGROUND Homepage

OWNGROUND 공식 홈페이지의 독립 보관·배포용 저장소입니다.

- 운영 도메인: <https://ownground.kr>
- 공개 정적 파일: `dist/`
- 지원 언어: 한국어, English, 日本語, Español, Tiếng Việt, Bahasa Indonesia, ไทย

## 배포 기준

`dist/index.html`을 공개 엔트리로 사용합니다. 저장소에는 공개 가능한 정적 자산만 포함하며, 비밀번호·API 키·메일 인증정보 등 비밀정보는 저장하지 않습니다.

현재 커밋은 OWNGROUND Narrative v0.2 공개본의 기준선을 보존하기 위한 것입니다. 호스팅 자동화와 도메인 연결은 별도 검증 후 구성합니다.
